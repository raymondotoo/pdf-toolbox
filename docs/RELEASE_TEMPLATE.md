# PDF Toolbox v1.0.0

PDF Toolbox is a standalone macOS utility for:

- merging PDFs
- date-sorted merging
- converting images to PDF
- splitting PDFs into single-page files
- removing scanner watermarks
- compressing scanned PDFs

## Downloads

- Apple Silicon: `PDF-Toolbox-macOS-Apple-Silicon-1.0.0.zip`
- Intel: `PDF-Toolbox-macOS-Intel-1.0.0.zip`

## Install

1. Download the correct zip for your Mac
2. Unzip `PDF Toolbox.app`
3. Drag it to `Applications`
4. Right-click and choose `Open` on first launch if macOS warns about the developer

## Notes

- Apple Silicon is for M-series Macs
- Intel is for older Intel Macs
- If macOS blocks launch, go to `System Settings > Privacy & Security` and choose `Open Anyway`
