# Install Guide

## Download the correct build

Choose the release asset that matches the Mac:

- `Apple Silicon`: M1, M2, M3, M4 Macs
- `Intel`: older Intel Macs

Download the `.zip` from the GitHub Release page, not from the repository file list.

## Install

1. Download the correct `.zip`.
2. Double-click the zip to extract `PDF Toolbox.app`.
3. Drag `PDF Toolbox.app` into `Applications`.
4. Open it from `Applications`.

## First launch warning

If macOS says the app is from an unidentified developer:

1. Right-click `PDF Toolbox.app`
2. Choose `Open`
3. Click `Open` again

If needed:

1. Open `System Settings`
2. Go to `Privacy & Security`
3. Click `Open Anyway`

## Optional: pin to Dock

1. Launch the app
2. Right-click the Dock icon
3. Choose `Options > Keep in Dock`
