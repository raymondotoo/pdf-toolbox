# Legacy Intel Release

Place the legacy Intel build here for release upload.

Recommended filename:

- `PDF-Toolbox-macOS-Legacy-Intel-1.0.0.zip`

Target:

- Intel Macs running macOS 10.14.6 Mojave or later

Build this with:

- an x86_64 Python 3.8 environment
- the legacy requirements file used by `./scripts/build_legacy_intel_release.sh`
